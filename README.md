# 🚗 Website Auto Escola Speed ABC

Website institucional desenvolvido em HTML5, CSS3 e JavaScript para apresentação de serviços, equipe, galeria de fotos e formulário de contato de autoescola.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Estruturação das páginas)
* **CSS3** (Estilização visual e layout)
* **JavaScript** (Interatividade e dinamismo)

---

## 💻 Como Visualizar o Projeto

1. Clone o repositório ou baixe os arquivos.
2. Abra o arquivo `Index.HTML` em qualquer navegador web para visualizar a página principal.
